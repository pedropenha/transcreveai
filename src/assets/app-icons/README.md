# Logos de aplicativos

Vetores de terceiros incluídos localmente, sem requisições em tempo de execução.
Obtidos em 2026-10-05 via API Iconify. As formas e cores dos vetores foram
preservadas; apenas um cartão branco de 48 × 48 com margem de 8 unidades foi
adicionado. O encaixe interno preserva a proporção original.

| Arquivo       | Coleção e identificador                                           |
| ------------- | ----------------------------------------------------------------- |
| `meet.svg`    | SVG Logos: `logos:google-meet-2020`                               |
| `teams.svg`   | SVG Logos: `logos:microsoft-teams`                                |
| `zoom.svg`    | SVG Logos: `logos:zoom-icon`                                      |
| `slack.svg`   | SVG Logos: `logos:slack-icon`                                     |
| `discord.svg` | SVG Logos: `logos:discord-icon`                                   |
| `webex.svg`   | Simple Icons: `simple-icons:webex`, cor de apresentação `#07C1E4` |

O Meet usa a versão multicolorida de 2020 para manter a identidade reconhecida
na interface existente; o vetor `logos:google-meet` da coleção atual tem outro
desenho. O Webex é o símbolo vetorial monocromático da coleção Simple Icons.

Fontes: [SVG Logos](https://github.com/gilbarbara/logos),
[Simple Icons](https://github.com/simple-icons/simple-icons),
[Iconify](https://iconify.design/).
As duas coleções distribuem seus vetores sob CC0 1.0. Textos das licenças
acompanham os arquivos; as marcas continuam pertencendo aos respectivos donos.
